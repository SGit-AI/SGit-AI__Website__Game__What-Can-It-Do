# Where this data came from

**The primitives, profiles, reductions, ceiling, picker, tree and mesh** were built at
[pki.sgit.ai](https://pki.sgit.ai) — repository `SGit-AI/SGit-AI__Website__PKI`, branch `dev`,
under `probes/` and `guess/` — and vendored into the games vault (`4evnlwrj`) on
6 September 2026. They were copied from that vault into this repository on 9 September 2026,
byte for byte, so that this site could become their home for contribution. CC BY 4.0.

| here | there |
|---|---|
| `primitives.json` | `probes/primitives.json` |
| `profiles/` | `probes/profiles/index.json` and each file it names |
| `reductions.json` | `probes/reductions.json` |
| `ceiling.json` | (authored in the vault, from brief v0.33.65) |
| `picker.json` | (authored in the vault) |
| `tree.json` | `guess/tree.json` |
| `mesh/graph.json`, `mesh/ontology.json` | `probes/mesh/graph.json`, `probes/mesh/ontology.json` |

`mesh/graph.json` is **compiled** — at pki it is generated from `probes/mesh/*/` sources by
`admin/build/gen_mesh.py`. The compiled form is what the game reads, so it is what ships
here; a change to the mesh should be made at its sources and recompiled, or this file will
drift from them.

**The mandates** under `mandates/` were authored here on 9 September 2026 as starting drafts.
No mandate data existed anywhere before that: the game collects a mandate from every player
and shipped none. They are the site's own claims about what a reasonable person wanted, and
the first thing on this site that a pull request should argue with.

**`pack.json`** is generated by the site build from everything above. Do not edit it.

From this point the canonical copy of these files is this repository. If pki.sgit.ai changes
its copy, that is a divergence to be reconciled by a pull request here, not a reason to
re-vendor over the top.
